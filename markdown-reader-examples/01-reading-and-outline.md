# Willow Garden field guide

The garden has one shared plan, but people arrive at different times. New volunteers need to find the right instructions without reading the full handover.

This guide keeps the day's work in sections. Start with [today's plan](#todays-plan), check the [watering schedule](#watering), or go straight to [closing the garden](#closing-the-garden).

> Leave the garden ready for the next person. Put tools back, record what changed, and report problems before leaving.

## Today's plan

We are preparing two beds for an autumn planting trial. The north bed needs fresh compost. The south bed already has seedlings and only needs water.

Work in pairs where possible. One person moves materials while the other keeps the path clear. Keep the gate open during the session so neighbours can see that volunteers are on site.

The plan is a starting point, not a reason to keep working in unsafe conditions. Stop if the path becomes slippery or a tool breaks.

### Before you begin

1. Read the notice on the tool shed.
2. Check the weather and the condition of the path.
3. Choose a task from the board.
4. Tell another volunteer which bed you will work on.

### What to bring

- Closed shoes with a firm sole.
- A water bottle.
- Gloves for moving compost and handling rough timber.
- A notebook if you prefer paper records.

You do not need your own tools. Shared tools are in the shed, arranged by task. Return each tool to its marked position rather than leaving it beside a bed.

## Watering

Water the soil near the roots. Avoid spraying leaves in direct sun. The goal is moist soil below the surface, not a wet-looking path.

Check before adding water. Push a finger a short distance into the soil. If the soil is still damp, leave that bed for the next session.[^soil]

### New seedlings

Use the small watering can with its rose attached. Pour slowly so the water settles into the soil rather than moving the seedlings.

A newly planted bed may need a second check later in the day. Record the time of the first watering so the next volunteer can make a decision from the same information.

### Established plants

Established plants need less frequent checks. Look for dry soil before watering. A bent leaf is not enough evidence on its own.

Keep the hose off the main path. If it must cross the path, ask another volunteer to stay nearby until the hose is moved.

## Compost and soil

Add compost to the north bed in a thin layer. Break up large clumps with a hand fork. Keep compost away from the stems of existing plants.

The labelled bin contains finished compost. The open bin contains material that is still breaking down. Use only the labelled bin for today's work.

### Moving compost

- Fill each bucket only as far as you can carry it without strain.
- Carry buckets along the clear side path.
- Put an empty bucket beside the bin for the next person.
- Sweep up spilled material before taking another load.

### Recording changes

Write down which bed received compost and how many buckets you used. The count helps the next group avoid adding a second layer by mistake.

Use plain descriptions. “North bed, four small buckets” is more useful than “soil improved”.

## Tools and shared spaces

Shared equipment lasts longer when each person returns it clean and dry. Knock soil from the blade with a brush. Do not strike a tool against the shed wall.

### Hand tools

Store forks and trowels in the low rack. Keep sharp edges facing away from the walkway.

- Check the handle before use.
- Report a loose blade or cracked handle.
- Put damaged tools in the marked repair box.

### Shared spaces

The table is for notes and breaks. Keep soil buckets and wet tools off it. Leave enough room for someone using a mobility aid to pass between the table and the beds.

Children can help with watering when an adult stays beside them. Keep the tool shed closed when nobody is collecting equipment.

## Notes from the previous session

The previous team replaced the latch on the gate. Close it gently while the new fitting settles.

~~Use the old blue hose.~~ Use the green hose stored beside the shed. The blue hose has a split near its connector.

The south bed has a label at each end. Keep both labels visible so people approaching from either path can identify it.

> A useful handover says what changed and what still needs attention. It does not need to describe every minute of the session.

## Questions and handover

If an instruction does not match the condition of the garden, ask the session lead before changing the plan. Write the answer on the task board so the next volunteer does not have to ask again.

### Notes

Leave a short record of completed work. Include the bed, the task, and anything the next team needs to check.

### Notes

Keep personal details out of the shared record. “Ask the session lead about the latch” is enough. The record does not need a phone number or a home address.

These two Notes headings are intentional. Outline keeps them as separate destinations.

## Closing the garden

Walk through the garden once before leaving. Look at the beds, the paths, and the shared table. A final check catches tools that a list alone may miss.

1. Return clean tools to the shed.
2. Coil the hose away from the path.
3. Put empty buckets beside the compost bin.
4. Update the task board.
5. Close the shed and check the gate.

If a task remains unfinished, say so in the handover. A clear note is better than a rushed job.
