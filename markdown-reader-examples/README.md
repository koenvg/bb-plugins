# Markdown Reader examples

Markdown source mixes document content with formatting syntax. In a long file, finding a section means scanning through both. Markdown Reader separates reading from source inspection with Preview, Raw, and Outline in one file tab.

These files use a fictional community garden project. They contain no private information, external image requests, or executable tasks.

## Open an example

Use Markdown Reader for each file.

1. [Reading and Outline](01-reading-and-outline.md) shows a long document with headings, prose, lists, quotes, and footnotes.
2. [Code and tables](02-code-and-tables.md) shows supported code highlighting and wide content that scrolls within the document.
3. [Raw and Refresh](03-raw-and-refresh.md) shows hidden frontmatter, exact source text, read-only tasks, and manual refresh.

## Things to try

- Make the file panel wide enough to see Outline beside the text. In a narrower panel, use On this page.
- Jump to a heading, then follow a footnote and its return link.
- Scroll a wide table or code block without moving the whole document sideways.
- Switch between Preview and Raw.
- Edit the status in the Raw and Refresh example with an editor, then use Refresh in the reader.

The examples are for local inspection. They are not evidence that installed-BB acceptance has passed.
