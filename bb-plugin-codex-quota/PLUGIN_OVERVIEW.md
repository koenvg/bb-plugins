## Account view

Remaining allowance by window, reset times when known, optional banked-reset availability, and a link to the official Codex Usage page. Readiness checks do not install a collector or import transcripts. Explicit install/repair/pause/resume controls enable host-local compact collection. Workspace totals count shared normalized paths once and show coverage gaps. Installation alone does not confirm loaded writers. Calendar reports, exact-thread attribution and transcript import are not available in this release. Existing Pi sessions need restarting to load the collector. An installed extension can outlive BB's UI/plugin; pause it on its host to stop new capture. The plugin does not redeem resets.
