Select Pi with subagents for a new BB thread. This is a separate provider, not a replacement for bundled Pi. It preserves Pi's ordinary tools, model/reasoning choices, dialogs, native skills, checkpoint forks, and manual compaction.

Subagent observation is unavailable in this baseline. It creates no child controls, native background activity, capture queue, or automation. Missing or disabled subagents do not block ordinary Pi work. See README.md for local checks and COMPATIBILITY.md for installation gates and unrun live checks.
