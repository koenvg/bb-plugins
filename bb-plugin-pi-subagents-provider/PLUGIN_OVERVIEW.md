Select Pi with subagents for a new BB thread. This is a separate provider, not a replacement for bundled Pi. It preserves Pi's ordinary tools, model/reasoning choices, dialogs, native skills, checkpoint forks, and manual compaction.

Open Subagents from the thread panel actions for read-only child detail. Supported native observations show task, recent transcript, final output, timing/activity, and parallel/nested ownership. Captures use bounded, schema-validated public thread extension state. Missing packages, unsupported commands, stale replies, timeouts, and missing artifacts do not become execution failures. There are no child execution controls or automation. Installed lifecycle and recovery acceptance remain required. See README.md, SUBAGENTS.md, and COMPATIBILITY.md.
