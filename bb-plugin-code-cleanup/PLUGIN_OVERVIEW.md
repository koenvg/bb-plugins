Code Cleanup offers optional project-specific guidance to record substantial adjacent cleanup as separate BB Tasks while keeping assigned work focused.

## What you get

- An initially disabled default for standard projects without an override, including future projects.
- A read-only five-column overview of saved settings for all standard projects, with effective On/Off, Default or Project override, Custom or Plugin default, direct enablement switches and conditional Use default.
- Confirmed-only row saves, one overview write at a time, project-specific failures and manual retry. Failed refresh keeps last saved values and blocks row writes until reload succeeds.
- A project-bound native prompt dialog. Click a project name or Edit prompt to open the same editor without writing, including for disabled projects.
- Edit/Preview, exact source text, saved-source metadata and a character count. Save closes only after confirmed persistence.
- Dirty Cancel, close and Escape use an internal discard confirmation. Reset confirms immediate persistence and keeps the dialog open on factory text. Later Cancel does not undo Reset.
- Independent enablement and prompt changes. Use default keeps custom text; prompt Reset keeps enablement. Legacy enabled and disabled choices stay explicit after upgrade.
- Draft protection on failed writes, dialog dismissal, and external edits. Conflicts require confirmed Reload before Save or Reset.
- One dynamic instruction block for enabled standard project sessions.
- Agent-created follow-ups require the BB Tasks CLI and a single linked tracker. The plugin does not create tasks or trackers.
- Changes apply to new sessions only. Existing provider sessions keep their guidance.
