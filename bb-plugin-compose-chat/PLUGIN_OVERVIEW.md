# Compose Chat

A Compose-inspired writing surface for BB's native chat. It joins the follow-up input and its existing footer into one rounded frame with a fine divider, keeps replies unboxed, and uses the active theme's colors and fonts.

The plugin changes styling only. BB still owns the draft, attachments, commands, provider and voice controls, and send/stop behavior. No settings or persistent data are added.

Requires BB 0.44 or newer. Disable Beautiful Chat or another chat restyler before enabling Compose Chat. Disabling Compose Chat restores BB's original appearance.
